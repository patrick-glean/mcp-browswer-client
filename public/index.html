Try it out

Everything runs in this page and a service worker its tabs share, so there's nothing to install. The MCP client is a library you choose under Runtime: Rust compiled to WebAssembly, or the official TypeScript SDK. Pick a server, then follow the steps. The guide stays open while you work. You can also add a server with + beside Servers: paste its URL, or your work email to find your company's Glean.

1. Pick a server

Glean, signed in with your work account

Enter your work email and the client asks Glean where your company's Glean is. Or paste your MCP server URL, from Glean's Your settings, then Third party apps and MCP, then the Connect to your AI apps with Glean MCP card.

Glean answers only pages from origins on its allowlist. If this page's origin isn't on yours, connecting fails with a network (CORS) error. If your Glean allows http://127.0.0.1:8888, run npm run start:glean in a clone and open the client there; otherwise ask a Glean admin to add this origin.

Sign-in opens in a pop-up window. The tokens stay in this browser and go only to that server. Then try its search tool with query onboarding.

Public servers, nothing to install

  • Context7 MCP 2026-07-28

    Try microsoft_docs_search with query service worker.

  • DeepWiki 2025-11-25, no sessions

    Try read_wiki_structure with repoName modelcontextprotocol/modelcontextprotocol.

These are third-party services. They only get requests when you connect or call a tool.

The mock server from the repo

It exercises every protocol path: modern and legacy servers, streamed replies, header parameters and a tool clients must hide. Run it from a clone:

python3 test_mcp_server.py

The command lets this site's origin through the mock's CORS check. Chrome will ask whether this site may access apps on your device; allow it so the page can reach localhost.

Add --mode legacy for a 2025-era server, --sse for streamed replies or --token secret for one that needs a bearer token.

2. Check the connection

The bar above the tools shows the server's status and the protocol it speaks: 2026-07-28 (modern), or a 2025 version marked legacy when the client fell back to the older handshake. Info has everything the server said about itself.

With the mock you should get 2026-07-28 (modern) and the tools echo, echo_region, count and ticket. It also offers broken_header, which is hidden on purpose; the tool list says why.

3. Run a tool

Click a tool, fill in its fields and choose Run (or press ⌘↵ or Ctrl+Enter). The result appears beside it; JSON has the whole reply. Optional fields left empty aren't sent.

Pre-fill fills the fields from what you last sent, a saved request or the tool's schema, and fields take {{variables}} from the environment in the top bar. Save keeps a request; run it again from Saved on the left to see what changed.

4. Chat through a tool

Open Apps in the top bar. Under Model, choose a server and tool and tick "Your message goes here" on a text field. Each message you send becomes that tool's input. With the mock's echo, every message comes back prefixed with "Echo:".

A model tool with a list field can run an agent loop: tick "The conversation goes here" on it, and the model also gets the instructions, your servers' tools and the conversation so far. Tool calls it writes in its reply run, and their results join the conversation.

5. Read the log

The dock at the bottom lists each connect, tool listing and call with its timing, and why the client chose the protocol it did. Trace has every HTTP request and response, and Runs every call. Copy or Download the log to share a problem.

If something goes wrong

Couldn't reach the server
It isn't running, or it doesn't allow this site through CORS. A local server reached from a public site also needs the browser's local network permission.
HTTP 404 or 405
The URL isn't the MCP endpoint, which often ends in /mcp.
HTTP 401
The server wants you to sign in, or a token. Choose Sign in in the bar above the tools, or paste a token under Info, then choose Connect.
Old behavior after a rebuild
Reload the page; the log should show "Loaded the Rust/WASM client" (or whichever library Runtime has chosen) with the new build time. If it doesn't, open Runtime in the top bar and reload the MCP client.
