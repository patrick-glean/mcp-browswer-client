Tool-call benchmark

Every MCP client library the app can run, the Rust/WASM one and the TypeScript SDK one, runs in this page's service worker, which calls call_tool on them directly, as the app's worker does: it measures the client layer and the HTTP exchange, without the page, the run history or the log. Every call echoes its text through the server's echo tool. The in-memory server answers inside the worker, so its numbers are the libraries' own work alone. Start a mock server first, such as npm run start:mock-mcp -- --mode modern. npm run bench runs all of this headlessly against three mock servers, plus a cold start and calls through the whole app.
