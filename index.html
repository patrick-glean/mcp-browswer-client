Try it out

This page is the whole MCP client: Rust compiled to WebAssembly, running in a service worker. Pick a server, then follow the steps. The guide stays open while you work.

1. Pick a server

Public servers, nothing to install

  • Hugging Face MCP 2026-07-28

    Try hub_repo_search with query whisper.

  • Context7 MCP 2026-07-28

    Try resolve-library-id with libraryName react and query hooks.

  • Microsoft Learn 2025-06-18, sessions, streamed replies

    Try microsoft_docs_search with query service worker.

  • DeepWiki 2025-11-25, no sessions

    Try read_wiki_structure with repoName modelcontextprotocol/modelcontextprotocol.

These are third-party services. They only get requests when you connect or call a tool.

The mock server from the repo

It exercises every protocol path: modern and legacy servers, streamed replies, header parameters and a tool clients must hide. Run it from a clone:

python3 test_mcp_server.py

The command lets this site's origin through the mock's CORS check. Chrome will ask whether this site may access apps on your device; allow it so the page can reach localhost.

Add --mode legacy for a 2025-era server, --sse for streamed replies or --token secret for one that needs a bearer token.

2. Check the connection

The server details show its status and the protocol it speaks: 2026-07-28 (modern), or a 2025 version marked legacy when the client fell back to the older handshake.

With the mock you should get 2026-07-28 (modern) and the tools echo, echo_region and count. It also offers broken_header, which is hidden on purpose; the Logs tab says why.

3. Call a tool

Click a tool under Available tools, fill in its fields and choose Call tool. The reply appears beside it, and Raw JSON shows the whole result. Optional fields left empty aren't sent.

4. Chat through a tool

On the Console tab, choose a server and tool under LLM target and tick Target for message on a text field. Each message you send becomes that tool's input. With the mock's echo, every message comes back prefixed with "Echo:".

5. Read the logs

The Logs tab lists each connect, tool listing and call with its timing, and why the client chose the protocol it did. Choose Everything to see every HTTP request and response. Copy or Download them to share a problem.

If something goes wrong

Couldn't reach the server
It isn't running, or it doesn't allow this site through CORS. A local server reached from a public site also needs the browser's local network permission.
HTTP 404 or 405
The URL isn't the MCP endpoint, which often ends in /mcp.
HTTP 401
The server wants a token. Paste it into Bearer token in the server details, then choose Connect.
Old behavior after a rebuild
Reload the page; the Logs tab should show "Loaded the WASM module" with the new build time. If it doesn't, open the runtime controls from the status pill and reload the WASM module.
